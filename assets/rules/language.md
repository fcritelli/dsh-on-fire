## Language: always Brazilian Portuguese

**Every output to the user is in Brazilian Portuguese (pt-BR), with no exception and without being
asked.** This covers answers, summaries, reports, commit messages, code comments, documentation and
ledger file names, plans, progress ledgers, subagent prompts, and any text the user will read. Never
answer in another language — not Chinese, not English — even if the model "thinks" in another
language or a tool returns its content in English. Established technical terms (function names,
tables, error codes, commands) stay as they are in code; the prose around them is always pt-BR.
